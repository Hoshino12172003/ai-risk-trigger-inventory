# Data Strategy

The study separates three levels of independence and variation.

## Level 1: Independent empirical domains

Candidate domains are Favorita, M5, and Olist. They are candidates only; no
external data has been downloaded.

## Level 2: Within-domain independent network constructions

Each empirical domain may support multiple independently constructed inventory
networks. The construction and independence criteria will be frozen after the
formal data audit.

## Level 3: Time-varying decision states

A decision state is defined as:

```text
s_(n,t) = network context
          + incumbent inventory
          + demand state
          + risk-control parameters
```

Increasing the number of decision states does not substitute for increasing
the number of independent networks or decision contexts. Generalization claims
must respect this hierarchy.
