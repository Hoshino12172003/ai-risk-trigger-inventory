# Terminology

| English term | Preferred Chinese term |
| --- | --- |
| risk trigger | 风险触发器 |
| exact optimization oracle | 精确优化 oracle / 精确优化器 |
| decision state | 决策状态 |
| incumbent inventory | 当前库存基准 |
| material reconfiguration | 实质性重配置 |
| missed trigger | 漏判 |
| decision loss | 决策损失 |

Avoid language that claims the AI replaces the optimizer, solves the inventory
problem, or directly determines inventory allocation. The AI screens whether
the exact optimizer should be invoked.
