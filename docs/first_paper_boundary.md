# Boundary with the Paper 2 Optimization Oracle

The optimization oracle belongs to
[`Hoshino12172003/budget-inventory-benders`](https://github.com/Hoshino12172003/budget-inventory-benders)
at frozen commit `51aebd06edf8f5d6d124d0f3eebdbb901e63274f`.

This repository neither copies nor modifies the robust inventory model or the
PRB-Benders implementation. It contains only the Paper 3 screening problem,
data contracts, evaluation contracts, and provenance needed to refer to that
oracle. No solver call is implemented here.
